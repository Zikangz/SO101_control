# SO101 机械臂高速度轨迹实验组会汇报说明

日期：2026-09-04  
实验对象：SO101 follower 机械臂  
实验目标：完成重新安装后的中位/校准验证，建立高速度、低抖动、可复现的桌面轨迹跟踪基线，并为后续“无人机 + 机械臂”空中操作仿真和实机迁移做准备。

## 1. 一句话结论

本次工作已经形成了可复现的 SO101 桌面高速控制基线：在不覆盖舵机 EEPROM PID、不开启额外低通滤波的条件下，`xz_vertex_diamond + z_bias=0.0083`、`f=0.1 Hz`、`100 x 40 mm` 轨迹视觉运动流畅，几何误差当前最小，可作为后续仿真和无人机挂载前的机械臂侧基准。

当前最佳实测结果：

| 指标 | 数值 | 说明 |
| --- | ---: | --- |
| 平均末端误差 | `4.700 mm` | 当前所有测试中最低 |
| RMSE | `5.037 mm` | 当前推荐主指标 |
| 最大误差 | `8.381 mm` | 仍需在空中操作前继续压低 |
| Z 高频抖动 RMS | `0.573 mm` | 视觉上基本流畅 |
| 最低电压 | `11.70 V` | 桌面供电可用，但上机前需重测压降 |
| 最大电流 | `253.5 mA` | 出现在当前最佳 diamond 轨迹测试中 |

## 2. 本次完成的工作

1. 重新安装 SO101 从臂和舵机后，完成舵机 ID 顺序设定、中位设置、factory-middle 校准和 ROS 配置同步。
2. 增加舵机状态检测工具，可读取 ID、位置、torque、mode、PID、温度、电压、电流等状态，用于确认硬件连接和上电锁定状态。
3. 建立“不覆盖 PID”的硬件桥启动方式：只打开 torque，不在启动时写入 P/I/D；舵机内部位置 PID 仍工作。
4. 对比多种 X/Z 平面轨迹：原始 sine、edge-vertex 8、zigzag、vertex diamond。
5. 对比多种补偿策略：常量 Z bias、phase-Z v1/v2/v3、二维 X/Z phase compensation。
6. 保存全部关键 CSV、profile 和图像，图像统一放在本目录 `so101_plots/`，便于汇报和后续复盘。

## 3. 最终推荐运行状态

| 项目 | 推荐值 | 理由 |
| --- | --- | --- |
| 轨迹形状 | `xz_vertex_diamond` | 避免 X 边缘和 Z 极值同时出现，几何误差最低 |
| 频率 | `f=0.1 Hz` | 视觉最流畅，抖动明显小于低速测试 |
| 轨迹幅值 | `x=0.050 m`, `z=0.020 m` | 保持 `100 x 40 mm`，没有靠缩小轨迹作弊 |
| Z 前馈偏置 | `z_bias=0.0083` | 当前最佳实测方案 |
| PID | 不改 EEPROM PID | 当前没有证据表明需要调 PID；避免引入新变量 |
| 低通滤波 | `SO101_LPF_ALPHA=1.0` | 当前视觉抖动不需要额外低通，避免增加相位滞后 |
| 二维 X/Z 补偿 | 暂不作为默认 | `phasexz_v1_safe` 实测回归，保留为对照数据 |

## 8. 汇报讲稿建议

### 开场：问题背景

这次实验的背景是 SO101 机械臂重新安装后，需要先确认中位、标定和控制链路是否可靠。最终目标不是单独桌面演示机械臂，而是为无人机挂载机械臂的空中操作建立一套可迁移的控制基线。因此本次重点不是追求单次最漂亮的轨迹，而是找到“速度、抖动、几何误差、可复现性”之间比较稳妥的组合。

### 方法：先稳定硬件，再做轨迹和补偿

实验流程分成四步。第一步完成舵机 ID、中位和校准，并把校准写入 ROS 配置。第二步使用不覆盖 PID 的硬件桥，保证舵机内部 PID 仍使用当前 EEPROM 默认值，避免在还没有充分数据时引入 PID 调参变量。第三步在 `f=0.1 Hz` 下比较多种 X/Z 轨迹形状，包括 sine、edge-vertex 8、zigzag 和 vertex diamond。第四步测试常量 Z bias、phase-Z 和二维 X/Z 补偿，判断哪一种能在不明显增加抖动的前提下降低几何误差。

### 结果：路径形状比当前补偿更关键

最重要的结果是：同样保持 `100 x 40 mm` 尺寸和 `f=0.1 Hz`，`xz_vertex_diamond + z_bias=0.0083` 的 RMSE 达到 `5.037 mm`，明显优于 edge-vertex 8 和 sine 路径。这个结果说明，当前误差不只是控制参数问题，轨迹形状本身会改变重力方向负载、关节组合和接近限位的程度。相比继续叠加更复杂的补偿，先选择更适合机械臂动力学和限位空间的路径，收益更直接。

### 讨论：为什么不调 PID、不加低通

本次没有修改舵机 PID，因为当前视觉抖动已经明显降低，主要问题变成可重复的几何误差。直接调 PID 可能同时改变阻尼、超调、发热和电流，难以判断收益来自哪里。低通滤波也暂时不加，因为它可能让轨迹更平滑，但会增加相位滞后，从而进一步放大几何误差。当前更合理的路线是保持 PID 和低通不变，把误差建模、路径设计和前馈补偿分开验证。

### 面向无人机：现在能做什么，不能做什么

当前结果可以作为无人机挂载前的机械臂侧基线，但还不能直接认为已经具备飞行操作能力。桌面测试已经证明机械臂在 `f=0.1 Hz` 下可以稳定、流畅地跟踪小范围 X/Z 轨迹；但上机后会增加机体振动、供电压降、基座姿态变化、气流扰动和安全约束。因此下一阶段应该先做仿真迁移：在 MuJoCo 或 IsaacLab 中复现机械臂模型、关节限位、速度限制、延迟和误差，再加入无人机移动基座，最后做全身控制和安全策略。

## 9. 后续工作建议

1. 固定当前桌面基线：`xz_vertex_diamond + z_bias=0.0083`，不要再把 `phasexz_v1_safe` 当默认方案。
2. 补充重复性实验：同一基线至少再跑 3 次，统计 mean/RMSE/max 的波动范围。
3. 做供电和线束验证：重点记录最低电压、电流峰值、温升，确认是否存在瞬时压降。
4. 建立仿真模型：先做机械臂单体 MuJoCo/IsaacLab，再加入无人机移动基座。
5. 做全身控制接口：把机械臂末端目标、关节限位、速度限制、急停、锁臂状态整理成仿真和实机都能复用的接口。
6. 后续再研究补偿算法：优先考虑小相位提前、重力/姿态相关前馈、迭代学习控制，而不是直接继续扩大二维拟合补偿。

## 10. 组会结论页可直接使用

本次实验完成了 SO101 机械臂重新安装后的校准、控制链路检查和高速轨迹跟踪评估。结果表明，在不修改舵机 PID、不开启额外低通滤波的条件下，机械臂可以以 `f=0.1 Hz` 流畅运行 `100 x 40 mm` 的 X/Z 平面轨迹。最佳方案为 `xz_vertex_diamond + z_bias=0.0083`，末端跟踪 RMSE 为 `5.037 mm`，最大误差为 `8.381 mm`。相比继续盲目调 PID 或叠加更复杂补偿，当前更有效的方向是选择更适合机械臂负载和限位特性的轨迹形状，并在此基础上建立可重复的误差模型。后续将把该桌面基线迁移到 MuJoCo/IsaacLab 等仿真环境，逐步加入无人机移动基座、供电扰动、姿态扰动和全身控制策略，为无人机机械臂空中操作做准备。
